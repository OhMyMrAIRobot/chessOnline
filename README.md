# Chess Online — онлайн-шахматы по WebSocket

## 1. Краткое описание
Веб-приложение для игры в шахматы через WebSocket. Клиентская часть реализована на React + TypeScript, состояние игры и синхронизация ходов выполняются в реальном времени через WebSocket-сервер на Node.js (модуль `ws`). Проект разделён на две папки: `client` (frontend) и `server` (backend).

## 2. Основной функционал
- Создание и проверка существования игровой комнаты (`/createGame`, `/getGame`).
- Синхронизация ходов между подключёнными игроками через WebSocket.
- Отправка/приём текстовых сообщений чата во время партии.
- Управление предложениями ничьей, сдачей, рокировкой и сменой фигур (промоция пешки).
- UI: доска, клетки, боковая панель, список потерянных фигур, таймеры и модальные окна для выбора имени/фигуры.

## 3. Технологический стек
**Frontend (client):**
- React 18 + TypeScript
- MobX (сторы для состояния игры)
- React Router
- Axios (HTTP-запросы к серверу)
- use-sound (звуковые эффекты)

**Backend (server):**
- Node.js + TypeScript
- Express (минимальный REST API для создания/проверки игр)
- `ws` (WebSocket)
- Nodemon для разработки
- dotenv для конфигурации через `.env`

## 5. WebSocket-схема и API
- HTTP endpoints (на сервере):
  - `POST /createGame` — создать игру. Ожидается JSON `{ id: string }`.
  - `GET /getGame?id=...` — проверить существование игры.

- WebSocket: сервер использует `ws`. Сообщения передаются в формате JSON и имеют поле `method` для определения типа действия. Часто используемые `method`:
  - `connection` — регистрация соединения в комнате (передаётся `{ method: 'connection', id: <roomId>, data: {...} }`).
  - `move` — ход игрока (передаётся с `id` комнаты и данными хода).
  - `message` — чат-сообщение.
  - `moveAndChange`, `leftCastle`, `rightCastle`, `giveUp`, `offerDraw`, `agreeDraw`, `rejectDraw`, `disconnect` — прочие действия/состояния игры.

Сервер рассылает входящее сообщение только клиентам с тем же `id` комнаты — это реализовано через присвоение каждому WebSocket поля `id` и фильтрацию `wss.clients`.
